# Best of Hermes

*Hand-picked Hermes Agent projects. Updated 25 Nov 2026.*

## Locutus · [@KeyArgo](https://github.com/KeyArgo)
**Plugins**
- **[hermes-game-center](https://github.com/KeyArgo/hermes-game-center)**: board and card games with real rules engines and a referee
- **[hermes-music-studio](https://github.com/KeyArgo/hermes-music-studio)**: describe a song, and Hermes writes and renders it
- **[hermes-revamp](https://github.com/KeyArgo/hermes-revamp)**: a Winamp-style music, audiobook and radio player
- **[hermes-aura](https://github.com/KeyArgo/hermes-aura)**: an AI-powered entertainment center for Hermes Desktop: music, films and YouTube with a visualiser that moves to your audio, all controlled by talking to Hermes
- **[hermes-omniscience](https://github.com/KeyArgo/hermes-omniscience)**: watch your agent live on a map, with replay
- **[hail-hermes](https://github.com/KeyArgo/hail-hermes)**: talk to Hermes out loud, even from a watch

**Custodian**
- **[custodian-hermes-guard](https://github.com/KeyArgo/custodian-hermes-guard)**: a fail-closed safety guard for Hermes Agent
- **[custodian-talaria](https://github.com/KeyArgo/custodian-talaria)**: the full governed Hermes experience on top of the guard
- **[custodian-kernel](https://github.com/KeyArgo/custodian-kernel)**: the authority and spend engine behind both

## Sahil · [@Sahil-SS9](https://github.com/Sahil-SS9) · X [@Sahil_Saghir](https://x.com/Sahil_Saghir)
- **[hermes-project-stewardship](https://github.com/Sahil-SS9/hermes-project-stewardship)**: durable project ownership for Hermes agent fleets
- **[agent-personas](https://github.com/Sahil-SS9/agent-personas)**: portable skills, personas and bundles across harnesses
- **[hermaguard](https://github.com/Sahil-SS9/hermaguard)**: adversarial bug-hunting code review with three parallel subagents
- **[Toolaria](https://github.com/Sahil-SS9/Toolaria)**: rescues oversized tool results before they flood context
- **[llm-judge-jury-executioner](https://github.com/Sahil-SS9/llm-judge-jury-executioner)**: a multi-LLM deliberation council
- **[hermes-walkie-talkie](https://github.com/Sahil-SS9/hermes-walkie-talkie)**: secure messaging between Hermes sessions
- **[Severian](https://github.com/Sahil-SS9/Severian)**: a local-first AI memory platform
- **[hermes-agent-radio-plugin](https://github.com/Sahil-SS9/hermes-agent-radio-plugin)**: a 24/7 Hermes radio station inside Desktop ([listen live](https://hermesagentradio.com/listen))
- **[agent-reel](https://github.com/Sahil-SS9/agent-reel)**: turns agent history into comic strips
- **[hermes-agent-mixer](https://github.com/Sahil-SS9/hermes-agent-mixer)**: dials for how much a coding agent may change
- **[Agent-Pocket-Notes](https://github.com/Sahil-SS9/Agent-Pocket-Notes)**: a private desktop notebook with agent runs
- **[house-style](https://github.com/Sahil-SS9/house-style)**: learns your project's style from your corrections
- **[hermes-share](https://github.com/Sahil-SS9/hermes-share)**: share sessions as redacted, revocable gists
- **[agent-run-debugger](https://github.com/Sahil-SS9/agent-run-debugger)**: a debugger for failed or expensive agent runs
- **[modernisation-engine](https://github.com/Sahil-SS9/modernisation-engine)**: gated repository modernisation
- **[hermes-branchpoint](https://github.com/Sahil-SS9/hermes-branchpoint)**: several agents build the same task, and a blind council picks the winner

## GottZ · [@GottZ](https://github.com/GottZ) · X [@iGottZ](https://x.com/iGottZ)

## Design Bakery · [@Pukujan](https://github.com/Pukujan)
- **[swarm-studio](https://github.com/Pukujan/swarm-studio)**: A whole creative studio inside Hermes: one prompt, and a crew of agents builds a website, web app, game, promo film and social posts on a live canvas ([marketplace page](https://hermes-agent.nousresearch.com/marketplace/swarm-studio))

## Sloptimus · [@mojomast](https://github.com/mojomast)
*His hackathon page: [hermes.rizz.click](https://hermes.rizz.click/)*
- **[EOH](https://github.com/mojomast/EOH)**: God's Eye View inside Hermes Agent: live 3D globe pane Hermes can drive, public-data tools, HUD via Hermes inference
- **[hyperrizz](https://github.com/mojomast/hyperrizz)**: A production-minded agent skill for distinctive HyperFrames films. Art direction, motion, audio, deterministic rendering, and verified delivery
- **[hermes-photo-to-part](https://github.com/mojomast/hermes-photo-to-part)**: Hermes plugin: turn photos, measurements or a 3D scan into a printable STL / editable CAD part, iterating against the original
- **[hermes-templeos](https://github.com/mojomast/hermes-templeos)**: TempleOS (TinkerOS) in a QEMU VM for Hermes: the agent and you share one live screen
- **[hermes-plugin-dev](https://github.com/mojomast/hermes-plugin-dev)**: Teach any coding agent to build Hermes Agent plugins: an Agent Skill + a Hermes plugin (scaffold & lint tools), distilled from shipping real plugins
- **[poptart](https://github.com/mojomast/poptart)**: Hermes Strudel Studio: live-coded music foundation
- **[hermes-stitchslop](https://github.com/mojomast/hermes-stitchslop)**: Drive the Stitch Slop embroidery digitizer from Hermes Agent: live pane, bridge protocol, DST/PES export. Four tools, no dependencies
- **[hermagotchi](https://github.com/mojomast/hermagotchi)**: Multiplayer agent-pet plugin for Hermes
- **[bundlebees](https://github.com/mojomast/bundlebees)**: Hermes plugin for orchestrating CUA bees (worker launcher, briefs, leases, verify)
- **[assetrizz-hermes](https://github.com/mojomast/assetrizz-hermes)**: Hermes plugin for the assetrizz 2D game-asset library: search, compose scenes, and preview in a dark pane
